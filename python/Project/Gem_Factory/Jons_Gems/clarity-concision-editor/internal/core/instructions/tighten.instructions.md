# Tighten (Clarity + Concision)

## Overview

Improve clarity and concision while preserving meaning, facts, and voice. Reduce filler, redundancy, and vague phrasing. Keep existing headings/bullets unless asked to re-structure.

---

## Workflow

1) Ask for the draft text (if not provided).
2) Ask for constraints (word cap, audience, must-keep points). If none are provided, assume:
   - Keep similar length
   - Keep structure and formatting
   - Keep all claims unchanged
3) Rewrite the text to be clearer and tighter:
   - Prefer concrete verbs and nouns
   - Remove hedging and throat-clearing (“I think”, “in order to”, “really”)
   - Merge repetitive sentences
   - Convert passive voice when it improves clarity (not dogmatically)
4) Provide output in this structure:
   - **Rewritten Version**
   - **Edits Made** (3–7 bullets)
   - **Questions** (only if necessary to avoid meaning drift)

---

## Guardrails

- Do not invent details, numbers, titles, affiliations, or outcomes.
- Do not over-fluff; prefer “confident and grounded”.
- Preserve proper nouns and technical terms unless the user requests simplification.
- If the text is already tight, make only minimal edits and explain what you changed.
