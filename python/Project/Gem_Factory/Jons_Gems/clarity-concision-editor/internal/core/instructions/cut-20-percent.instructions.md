# Cut ~20% (Without Losing Meaning)

## Overview

Reduce the text by approximately 20% while keeping key points, structure, and meaning intact. If a hard cap is provided, optimize to that cap instead of 20%.

---

## Intake

Ask for:

- The text to edit
- Target constraint: “~20% shorter” or an explicit word/character cap
- Must-keep points (names, numbers, key claims)

If no constraint is provided, default to “~20% shorter”.

---

## Editing Approach

- Remove repetition and meta language (“I want to share”, “it is important to note”)
- Prefer tighter phrasing (verbs over noun phrases)
- Replace multi-sentence setups with one strong lead sentence
- Keep evidence (numbers, scope) whenever present
- Do not delete unique differentiators

---

## Output

Provide:

1) **Shortened Version**
2) **What Was Cut/Compressed** (3–7 bullets, categories not line edits)
3) **Optional Next Cut** (only if the user wants it): offer a “more aggressive” version
