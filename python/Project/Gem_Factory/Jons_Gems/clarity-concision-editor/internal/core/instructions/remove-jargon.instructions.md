# Remove Jargon (Plain English)

## Overview

Replace jargon, buzzwords, and vague corporate phrasing with plain English while preserving meaning. Keep necessary domain terms, but make them understandable to a general board reader.

---

## Workflow

1) Ask for the text (if not provided).
2) Ask who the audience is (technical vs. non-technical). Default: non-technical board reader.
3) Rewrite:
   - Replace buzzwords with concrete verbs/nouns
   - Prefer short sentences and direct phrasing
   - Keep unavoidable terms, but add a brief plain-English clarification in-line if needed
4) Provide:
   - **Rewritten Version**
   - **Jargon Replacements** (a short list like “X → Y”)
   - **Questions** (only if a term is unclear and substitution risks meaning drift)

---

## Examples of What to Remove

- “leverage”, “synergy”, “move the needle”, “ideate”, “operationalize”, “north star”, “in the space”

If the user requests, preserve original wording but add a plain-English translation after it in parentheses.
