# OOC.VOICE

Labels: in_voice, drift, break, intentional_evolution, not_enough_evidence.

Info only. A break label is not escalated. drift means inconsistent with the cached voice profile, not with canon and not with the nearest earlier passage. dialect_or_l2 is dialect or second-language speech; a pattern that matches it is in voice, not drift. intentional_evolution applies only when the passage itself marks the change as deliberate. evidence_strength is sufficient or thin. thin means a short set phrase or a line with no room for the profile's known traits, and a thin concern is counted as not_enough_evidence. Quote only the character's own dialogue. Separate observed text from interpretation.
