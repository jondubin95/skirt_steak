# Project Skills

These skills are slash-invoked only. They do not auto-apply from context.

| Skill | Invoke with |
| --- | --- |
| Handoff notes | `/handoff-notes` |
| Clarity & concision editor | `/clarity-concision-editor` |
| Paranoid market analyst | `/paranoid-market-analyst` |
| Operating behavior | `/operating-behavior` |

Each `SKILL.md` sets `disable-model-invocation: true`. In Cursor, keep them available under Customize → Skills, but do not put them in an always-on Custom Mode unless you want that skill on for the whole chat.

`AGENTS.md` is still a repo guardrail file and is separate from these skills.
