# Monthly board minutes doc setup

Use when the user asks to set up the doc for this month's board meeting minutes: a blank fill-in skeleton from the agenda in the chat, using last month's minutes as the format.

# Purpose
Before each monthly board meeting, turn a copy of last month's minutes into a blank skeleton the user fills in live. Never write meeting content for them.

# Steps
1. Find the agenda. Read the officers WhatsApp chat (read-only, via computerUse on the box browser) for the agenda list, ordering requests, who can't attend, who will be late, and any voting items such as bonuses or amendments. Also check the board chat. Read only. Never type in or send to any chat. Be careful in the sidebar search: type only into the search box.
2. Find the target doc. Usually a copy of last month's minutes named "<Month> <Year> Board Meeting Minutes <YYYYMMDD>" in Drive. If none exists, ask whether to copy last month's doc (new copy; never edit the original). Read the Minutes tab and the Notes tab with the Google Docs read_document tool.
3. Back up first. Save the full current text to a box file before editing.
4. Edit the Minutes tab in place, keeping the existing formatting: date line, title line with the line break, "In attendance:" block, HEADING_3 section headings, bullets, and bold "Motion:" paragraphs. Do not touch the Notes tab, last month's original doc, or share/comment.
5. Attendance: one bullet "Full board (unassigned): <all names>", then blank bullets "Officers:", "Trustees:", "Not in attendance:", "Others:". The user sorts names themselves. Leave late or absent people out of it.
6. Sections: the agenda order from the chat. Standing items stay as blank fill-ins: D'var Torah ("Delivered by "), Accept Minutes (motion with blank names about last month's meeting), and Adjournment (blank motion). Each other section gets one empty bullet.
7. Voting items: add a blank motion in the same style. If the chat gave standard motion wording (for example for bonuses), use it with blank names and amounts. For a constitutional amendment, keep the amendment text so it can be read aloud, drop last month's discussion narrative, and add a blank motion/vote line.
8. Keep sensitive details out of the doc: employee names, amounts, performance comments, grievance specifics, and executive-session matter. Leave those blank.
9. Remove last month's narrative (reports, discussion, old motions, old attendance). Do not invent content.
10. Read the whole tab back to verify order, headings still HEADING_3, amendment text intact, Notes untouched. Use revision guards on writes, re-read indexes after each write, and edit bottom to top when deleting.
11. Tell the user the doc link, the sections in order, anything left from last month they should reword, and that formatting indents of new bullets could not be visually checked.

# Rules
- Read-only on WhatsApp and Drive except the one target doc. Draft nothing to board members unless asked.
- In a group chat, post only brief status; put sensitive chat details in the 1:1 only.
- Doc edits can be delegated to a background worker, but give it the exact structure above.
